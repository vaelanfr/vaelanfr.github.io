Illustrative approach for ECF

A proportionate, co-designed path to adoption

This four-step outline describes a proposed intervention approach, not a previously delivered assignment for a philanthropic grant-making organisation.

01 · DiagnoseStart with decisions and users

Listen to Strategy and Impact, Strategy, Data and programme teams. Map objectives, existing evidence, decisions, review cycles and reporting effort.

02 · Co-designBuild a useful impact framework

Agree strategic learning questions, definitions, proportionate indicators, qualitative evidence, data responsibilities and accessible guidance.

03 · PilotLearn by testing with teams

Pilot tools and reflection routines with selected teams; use feedback to improve usability and connect insights to strategic reviews.

04 · EmbedEnable long-term ownership

Clarify governance, responsibilities, simple workflows, documentation and review mechanisms so the framework stays useful after handover.
